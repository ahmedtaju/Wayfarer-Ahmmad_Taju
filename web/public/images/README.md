# Local reference imagery

The three category images were copied from image sources in the user-supplied
`stitch_wayfarer_travel_discovery_guide.zip` directory mockup and saved locally.
They provide illustrative category imagery rather than verified photographs of
each listed place. The interface does not fetch these images from external hosts.

`placeholder.svg` is a local fallback used if an image cannot load. Typography
also uses local system font fallbacks so the application works without font CDNs.
